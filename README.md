# 大老二 Big Two - 網頁版

單機挑戰三家電腦，免下載，手機電腦點開即玩。

## 玩法
- 支援單張、對子、順子、同花、葫蘆、鐵支、同花順自動判定
- 首攻必須包含 ♣3
- 難度：簡單 / 普通 / 困難
- 計分：剩 8-9 張扣分 ×2，剩 10 張以上 ×3，每留一張 2 罰分再 ×2

## 功能
- 悔牌、牌局重播、牌譜
- 電腦思考中動畫、音效、動畫
- 今日挑戰（每天一副固定牌，當天首勝 +50 分）
- 個人戰績統計、每日挑戰排行榜
- 中斷續玩：每出一手自動存檔，重新整理可回到上一局
- 記牌器：看每種點數已出幾張、你手上幾張、對手還可能有幾張、炸彈警戒

## 本地測試
直接用瀏覽器開啟 `index.html` 即可。

## 部署
上傳到 GitHub Pages 即可線上玩。
